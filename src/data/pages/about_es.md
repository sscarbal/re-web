**Sitio web del autor**: https://howduudu.tech/en/

**URL del tema**: https://astro.build/themes/details/designphotographyportfolio/

**Repositorio del proyecto**: https://github.com/pysunday/DesignPhotographyPortfolio

**Introducción del tema**: Este tema está construido con Astro y diseñado para diseñadores y fotógrafos para mostrar sus portafolios de imágenes.

**Declaración especial**: Las imágenes utilizadas en este tema provienen de los sitios web oficiales de otros diseñadores/fotógrafos y se utilizan únicamente para demostraciones funcionales.

**Características soportadas por este tema de Astro**:

1. Cambio de tema claro/oscuro;
2. Soporte multilingüe basado en i18n;
3. Construido con React, Tailwind CSS, DaisyUI, AlpineJS y HeroUI;
4. Amigable con SEO;
5. Diseño responsivo;
6. Altamente personalizable;
7. Sitemap;
8. Análisis integrados;
9. Listo para usar desde el primer momento;
10. Gestiona portafolios y contenido de páginas con archivos Markdown;
11. Almacena imágenes por portafolio y genera automáticamente versiones comprimidas;
12. Mejora la experiencia del usuario con efectos hover y animaciones de fuentes;
13. Visualización de imágenes estilo mampostería con renderizado estable;
14. Sistema de comentarios integrado basado en Giscus;
15. Etiquetas Open Graph y generación dinámica de imágenes OG para compartir en redes sociales;
16. Soporte PWA, permitiendo instalación en escritorio con un clic desde el navegador.
